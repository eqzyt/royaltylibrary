# Changelog

## 1.0.0

- Published the executor-ready single-file UI and runtime extension API.
- Rounded clipping for the outer panel and content cards using CanvasGroup + UICorner.
- Added reusable pages, sections, labels, buttons, toggles, selectors/dropdowns, sliders, and text inputs.
- Added tween conflict management and non-blocking screen/loading transitions.
- Improved password editing for middle insertions/deletions, picker touch input, and malformed saved-color handling.
- Documented the local-only demo authentication and the requirements for a future server-backed key system.
